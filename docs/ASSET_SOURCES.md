`LDIoaomQNQcsA88c7O9yZ4KMCoOg4Ko20yygg_vb.woff2` (SHA-256
`cd8db90cd950e26bc8761f65d323588bd5cd112d326d6d322bc7c8ea86771215`).

para tokens, shell y convenciones visuales; no aporta lógica de negocio a Tablio.
